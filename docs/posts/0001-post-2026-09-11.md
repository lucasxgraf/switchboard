I've started a new project: Switchboard, a self-hosted LLM gateway.

By December I want to answer one question with a measured number: how much cheaper can LLM requests get without the answers getting worse?

My own apps run on free tiers and cost me almost nothing. The question gets interesting once traffic grows, and I want to learn how to measure it properly.

Switchboard sits in front of several LLM providers. To my apps it looks like an OpenAI-compatible endpoint, and behind it there's routing, caching and fallback. A dashboard shows cost, latency and quality. LiteLLM and OpenRouter already do this, and they do it better. For me the point is being able to explain every decision in it.

Two of my apps, Code-A-Cuisine and Quizly, call Groq and Gemini directly today. Both are moving behind the gateway, so Switchboard has to handle real traffic.

The most exciting part for me is the measurement. 50 to 60 hand-written tasks run against every model, and a judge model scores the answers. To check whether I can trust the judge, I score 50 answers myself. If the judge is off, every number after that is worthless. The final number will come from these tasks. My own traffic is too small and too one-sided for a reliable figure.

One big difference from my newsletter project: there, Claude Code wrote every single line. This time I type every line myself, test first, then code. Claude is my sparring partner and reviewer. Along the way I want to get better at React, TypeScript and Tailwind, and I'm learning Django under ASGI, streaming with httpx, Sentry and setting up CI/CD for the first time.

After the first three days, the settings cover three environments (local, CI and later the VPS), there's a first endpoint with a test, and CI checks lint, types, migrations and tests on every pull request. pytest, ruff and mypy were all new to me.

To make sure branch protection really works, I broke a test. On purpose. The merge button stayed locked.

What's next? Code-A-Cuisine will run in production through the gateway, and I'll see every call in the database.
